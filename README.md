# Claude Skill: Làm website WordPress bằng AI (tiếng Việt)

Skill miễn phí cho Claude giúp **người mới, không biết code** tự làm một website WordPress + Elementor chuyên nghiệp, từ lúc hỏi đáp về doanh nghiệp đến khi website chạy trên tên miền riêng.

📺 Video hướng dẫn: [YouTube – Hùng Phạm](https://www.youtube.com/@hungpham_channel) · 🌐 [hungpham.vn](https://hungpham.vn)

**⬇️ Tải skill:** [website-wordpress-vn.zip](https://github.com/hunghanghai/claude-skill-wordpress-vn/releases/latest/download/website-wordpress-vn.zip)

## Skill làm được gì

1. **Hỏi đáp về doanh nghiệp** bằng tiếng Việt, từng câu một, rồi tóm tắt thành bản brief.
2. **Xử lý logo & ảnh thật** bạn để trong thư mục `media/`: chấm chất lượng từng ảnh, tách nền logo, tạo favicon, nén ảnh, xoá dữ liệu GPS, đọc chữ trong ảnh bảng giá/thực đơn.
3. **Đề xuất 3 phong cách thiết kế** và dựng bản xem trước trên máy để bạn duyệt, **trước khi tốn tiền hosting**.
4. **Hướng dẫn mua hosting + tên miền** và cài WordPress (nếu bạn chưa có).
5. **Kết nối Claude với website** qua Elementor MCP.
6. **Dựng từng trang bằng Elementor**: mọi phần đều là phần tử Elementor thật, bạn tự sửa được sau này.
7. **Form liên hệ/đặt lịch** bằng Fluent Forms, chỉnh header/footer, kiểm tra 8 tiêu chí, rồi xuất bản.

Phù hợp nhất với website giới thiệu doanh nghiệp nhỏ 3–7 trang: quán ăn, spa, nha khoa, dịch vụ sửa chữa, studio, homestay, freelancer… Chưa hỗ trợ shop có giỏ hàng (WooCommerce).

## Cần chuẩn bị

- Ứng dụng **Claude desktop** (Mac/Windows) với gói trả phí, để dùng tab **Code**
- Hosting + tên miền (skill hướng dẫn mua nếu bạn chưa có; đã có hosting ở đâu cũng dùng được)
- Logo và ảnh thật của doanh nghiệp (ảnh chụp điện thoại là được). Chưa có cũng làm được, bổ sung sau.

## Cài đặt

1. Tải file [`website-wordpress-vn.zip`](https://github.com/hunghanghai/claude-skill-wordpress-vn/releases/latest/download/website-wordpress-vn.zip) (**không giải nén**; nếu trình duyệt tự giải nén thì chuột phải vào thư mục → Nén lại).
2. Mở Claude → **Customize / Cài đặt → Skills → Add skill → Upload skill** → chọn file zip.
3. Đảm bảo công tắc của skill đang **bật**.

## Sử dụng

1. Mở tab **Code** → tạo phiên mới → mở một thư mục trống (ví dụ `Documents/Website cua toi`).
2. Chọn model mạnh nhất hiện có.
3. Gõ: **`Làm website cho mình`**
4. Trả lời các câu hỏi. Khi được hỏi, chép logo vào `media/logo/` và ảnh vào `media/hinh-anh/`.
5. Khi Claude bảo mở phiên mới, gõ **`Tiếp tục website của mình`** để làm tiếp đúng chỗ đã dừng.

## An toàn & minh bạch

- Skill **không bao giờ** hỏi mật khẩu hosting hay WordPress.
- Claude kết nối website bằng **mật khẩu ứng dụng** riêng, thu hồi được bất cứ lúc nào (Thành viên → Hồ sơ → Mật khẩu ứng dụng).
- Claude không tự mua gì, không tạo ảnh bằng AI, không bịa giá hay thông tin cho doanh nghiệp thật.
- Skill chỉ là các file chữ (`.md`). Bạn có thể mở ra đọc trước khi cài.
- **Skill có chứa link giới thiệu (affiliate) của tác giả** cho iNET (hosting, tên miền) và Novamira. Claude chỉ đưa link khi bạn cần mua và luôn nói rõ đó là link giới thiệu. Bạn không phải trả thêm gì.
